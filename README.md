**Disease Prediction System using Machine Learning**
This repository contains a web-based Disease Prediction System that uses machine learning to predict possible diseases based on user-reported symptoms. It is built with Python and deployed using Streamlit, offering a user-friendly interface.

**Features**
Predicts diseases based on selected symptoms

Uses pre-trained machine learning models

Interactive and easy-to-use Streamlit UI

Fast and lightweight – runs locally or deployable on cloud platforms

**Model**
The system uses a machine learning model (e.g., Decision Tree, Random Forest, or similar) trained on a dataset of symptoms and associated diseases. The model takes multiple symptoms as input and predicts the most probable disease.

**Technologies Used :-**
Python

Streamlit

Scikit-learn

Pandas

NumPy

Jupyter Notebook (for model development and training)

**How to Run**
Clone the repository:
git clone https://github.com/your-username/disease-prediction-system.git
cd disease-prediction-system
Install dependencies: (Make sure you have Python 3.7+ and pip installed)

pip install -r requirements.txt
Run the Streamlit app:

streamlit run apps.ipynb
